### AI vs ML vs DL
-- AI: Artificial Intelligence
- AI is the tasks a computer can make decision, and usually, AI will make a decision by mimicking solve problem of humans.
- ex: When I talk to AI: "Please let me know which type of computer I should buy." AI will mimicking these activities of human to propose a solution to problem. More specifically, the AI system will collect these feature of these computers like price, RAM, CPU,..to make a last decision for me.

-- ML: Machine Learning
- ML is the tasks a computer can make decision based on data, like experience of humans.
- ML similar AI, but ML is a part of AI.
- ex: When I talk to ML similar anything I talk to AI, ML will be base on data to make a decision. More specifically, ML will be find out these information in the data to propose a solution for problem.

-- DL: Deep Learning
- DL is a part of Machine Learning.
- DL is the field of machine learning by use certain object called "neural networks".
