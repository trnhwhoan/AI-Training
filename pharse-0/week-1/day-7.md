## Chapter 1

### From Foundation Models to AI Engineering
- AI Engineering is a process build applications base on foundation models.
- AI Engineering takes advantage of available models.

#### Factor 1: General-purpose AI capabilities
- Foundation models can be work various types of tasks.
                   Foundation Model
                       ↓
       ┌───────────────┼───────────────┐
       ↓               ↓               ↓
   Translation    Summarization    Question Answering
- It becomes useful in more aspects of life and can automating or partially automating a great many tasks.
- These ability can help create strong models in the future.
- Mindset of AI Engineering:
  - Chose fit model -> Write prompt -> Connect product's data -> Build interface -> Handle answers -> Checking system.
 
#### Factor 2: Increased AI investments
- The success of ChatGPT had promote investment in AI => profiting from AI investments is becoming more attractive.
- AI used in product and work process of company.

#### Factor 3: Low entrance barrier to building AI applications
- Model as a service help build applications became to easier.
- Models provided through API, API receive question and reply result for user.
                          App
                           ↓
                          API
                           ↓
                   Foundation Model
                           ↓
                      AI Response

#### Build from scratch & Build on top of foundation models
- **Build from scratch** is build a model from scratch, need many data, GPUs, infrastructure, machine learning expertise, training time and money.
- **Build on top of foundation models** is take an existing model and build application.
                    GPT / Gemini / Claude
                            ↓
                           API
                            ↓
                     Your application
                            ↓
             Chatbot / Search / AI assistant / ...
