### Review
#### Data, Features & Labels
- **Machine Learning** learn from data to looking for rules and make a prediction.

  -- Have: Dataset, Sample, Feature (X), Label/taget (y).

#### Models, Training & Prediction
- **Model** - models learn the relationship between X & y.

- **Training** - process learn from data.

- **Prediction** - use things studied to prediction new value.
  
- **Error** - discrepancy between prediction value and actual value.

  ***Signed Error** = ŷ - y*

  ***Absolute Error** = |ŷ - y|*

#### Types of Machine Learning

| Type | Meaning | ex |
| --------- | --------- | --------- |
| **Supervised**    | Learning from labeled data   | Prediction spending   |
| **Unsupervised**    | Find function in data without a target label   | Analyst customers   |
| **Regression**    | Predict number value   | Revenue   |
| **Classification**    | Predict class/group   | Are you going to make a purchase?   |

#### Train/Test Split & Overfitting
- **Training Set**: use to training
  
- **Testing Set**: use to rating on data not yet used for training.
  
- **Overfitting**: model that overfits the data and bad general.
  
- **Data Leakage**: invalid information from outside training process fit into the model.
