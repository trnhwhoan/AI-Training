#### Why enterprise often start from AI internal?
- Enterprise often prioritize **internal-facing** before.
  - ex:
    - Internal: AI search internal document for staff.
    - External: Chatbot talk direct with costumer.
    -> Helps:
      - learn how to implement AI
      - build AI engineering privacy
      - decrease risk about data privacy
      - decrease risk compliance
      - decrease consequence if AI commit a serious error
- Foundation models can do many things, but their practical applications are often limited to a specific scope.
    - Foundation model -> can do many things
    - AI application -> allow some task.

### Coding
#### Coding is use case most popular of GenAI
- AI fit with coding because:
  - Code has clear structure.
  - AI have many sample code to learn.
  - Dev can describe request through natural language -> AI create code.
  - AI can support from coding -> test -> documentation -> refactor.
    - ex: "Create for me a API login by Java Spring Boot"
      -> AI can create mainly original code.
#### AI not only coding
- AI can support many tasks in Software Engineering:
  - Web/PDF -> data: AI can extract data.
  - English -> code: AI can transfer request to code.
  - Screenshot -> website: AI can create UI/code.
  - Code -> code: AI can transfer framework/language.
  - Documentation: AI can write document.
  - Testing: AI can create test.
  - Git/GitHub: AI can create commit message.
    => AI can join almost the entire life cycle of Software Development.

#### Does AI do everything equally well?
**Noooooooooooooo**
- If it is a repetition task, have pattern -> AI is quite powerful.
- If it is a task requiring significant reasoning -> AI needs human control.
- If it is an extremely complex problem → AI might not necessarily be of much help.
    => AI is not just a coding tool — it can assist across many software engineering tasks and make developers more productive.
