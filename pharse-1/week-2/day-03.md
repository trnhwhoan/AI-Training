### Supervised vs. Unsupervised Learning
#### Supervised Learning
- The models learn from data have **features (X)** and **labels (y)**.
- ex: A system forecast score base on time learning.
<img width="439" height="189" alt="image" src="https://github.com/user-attachments/assets/d44775ce-ddb1-484a-b00d-9ca9c6a76657" />
  -- Models know the correct answer in training process to learn relationship of X and y.

#### Unsupervised Learning
- Model analyst data **no target labels are provided**, aimed at discovering underlying structures or groups.
- ex: Glowee want to segment customer to these groups with similar purchasing behavior.
  <img width="614" height="191" alt="image" src="https://github.com/user-attachments/assets/f77411c6-13b8-48dc-ac10-6f6fe8570f12" />
   -- A **clustering** function can identified two customer groups have different behavior without need known group label.
- **Clustering** use to automatically partitioning an unlabeled dataset into smaller groups (clusters) such that the elements within the same group are as similar to each other as possible, while being distinct from those in other groups

### Regression vs. Classification
- **Regression** - predict a continuous numerical value, such as house prices, temperature, or scores. The basic models is *Linear Regression* 
- **Classification** - predict a class or category. The basic model is *Logistic Regression*
